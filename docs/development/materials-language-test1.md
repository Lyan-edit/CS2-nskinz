# 0.7.6 材质与语言测试版

保留现有 nSkinz UI 布局、配色、样式、饰品编辑和预览。地图页底部新增“地图材质：打蜡反光”独立应用项；新增“设置”页中的语言选项。

## 使用

1. 加载测试 DLL，打开原控制面板。
2. 在“地图更换”页向下滚动到“地图材质：打蜡反光”。勾选启用，选择与当前场景对应的基准地图。
3. 点击“独立应用并重载 Demo”。只提交材质设置，保留其它尚未应用的编辑；不需要 XUID，不做饰品实体重写。
4. “恢复原材质并重载”关闭此项并重载。已有引擎资源缓存可能需要完整重启才能释放。
5. 在“设置 → 语言 / Language”切换简体中文或 English，立即生效并自动保存。默认中文，只有一个 DLL。

支持 8 张基准地图；Mirage Water 和 Inferno Water 可使用对应基准。未知工坊变体不自动匹配。材质启用、资源请求命中可在该项“材质状态”查看；命中次数代表文件重定向，不代表最终 GPU 画面已确认。

## 隔离与兼容

语言偏好保存在独立的 `nSkinzCS2.settings.json`；切换不修改物品 ID、XUID 或应用状态。两个目录由同一本机游戏数据导出。每次运行仍从空应用状态开始。

饰品路径沿用当前版本：枪械、刀、手套和五槽贴纸热修；挂件临时 Demo 重建；工坊换图保留。地图材质使用独立作用域及地图匹配检查，关闭或切换到其它地图后不再重定向。缓存准备在工作线程执行，不在渲染回调中解包、计算文件哈希或写盘。
