# 枪械热修改与 HUD 名称同步

2026-11-04。

v0.7.0 的名称缓存失效和右侧图标标签提交仅由刀具调用。枪械热修改虽然会写入涂装、物品身份和自定义名称，但没有调用最终图标文字刷新，存在材质已变化而 HUD 保留旧名称的可能。

当前本地修复增加枪械调用。只在目标玩家的活动武器匹配配置、完整实体代次有效、本次字段应用和材质刷新签名均完成、涂装属性与 fallback 一致、物品身份／账户／自定义名称符合请求时，失效原生物品描述并重新取得完整本地化名称。名称经已有原生 HUD 更新回调提交到对应句柄和枪型的图标。

队列按玩家和完整武器句柄去重。刀、主武器和手枪分别保留请求，每份配置／图标只提交一次。seek、配置修订、所有权变化、句柄复用及旧物品身份会使旧请求失效。

手套不属于右侧武器选择列表，没有对应的图标名称行。其物品字段、自定义名称和外观验证继续由手套路径处理。默认 T／CT 手套与生成 Demo 中的手套遵守临时 Demo 重建规则。

验证使用本机 CS2 2000940 的物品名称、武器选择表和标签 setter 字节证据。回归覆盖 AK、手枪和刀图标的独立选择、错误枪型／手套定义拒绝以及不同饰品的独立提交状态。最终 HUD 画面仍需用户在游戏内确认。
