# 贴纸预览与实际 Demo 位置不同步（2026-11-01）

## 现象与结论

预览画布上两张贴纸分开，实际游戏内却重合。已确认有两个独立原因：自定义位置错误地把 schema 零当成“自身槽位”，以及保留原位模式的预览没有读取原 Demo 的投影槽和偏移。

## 2026-11-02：自定义槽位的 schema 语义错误

安装客户端 2000939 的原生贴纸读取链提供了直接证据：`client.dll+0x78A8AC` 给整数 getter 的默认参数赋值 `-1`，读取贴纸组件 6（schema）；`+0x78A8C3` 比较结果是否为 `-1`，仅在该值下保留逻辑槽号，否则用读取到的值选择投影面。getter 位于 Econ 物品虚表 `+0x38`，实现为 `+0x113AF10`。

因此字段缺省／`-1` 表示自身投影槽，显式 `0` 则永远表示第一个投影槽。旧代码给原生自定义槽位 1–4 都写 `0`，但预览按各自投影槽绘制，直接造成实际与预览错位、贴纸重合。此错误同时影响实时参数更新和临时 Demo 序列化。

现在两个写入端统一通过 `ResolveSerializedStickerSchema` 选择预览所用的同一投影槽。AK 的五槽写入 `[0, 1, 2, 3, 1]`；第五槽借用第二个投影槽并叠加已有校准偏移。输出回读以逻辑槽作为缺省 schema，对显式 `0` 不再回退到逻辑槽，对 `-1` 才回退。预览直接使用回读后的有效 schema。

“使用预设位置”原先仅关闭自定义开关，仍保留来源的 offset/schema，并未真正恢复标准位置。现在该按钮启用显式变换并写入当前槽位标准起点；关闭自定义开关的含义仍是保留来源位置。已有配置的用户偏移值保持原单位，不进行猜测式迁移。

## 保留原位模式的独立问题

在“预设／保留原位”模式下，临时 Demo 重建器只替换已有槽位的贴纸 kit，故意保留原 Demo 内的 wear、scale、rotation、offset X/Y 和 schema。旧预览却始终画目录／VMDL 的标准槽位，没有读取输出 Demo 中真正保留下来的变换。因此原 Demo 中两个逻辑槽位只要共用 schema 投影面，或原 offset 本来就很近，实际画面就可能重合，而旧预览仍显示五个标准位置。

## 修复路径

1. 重建器在写完临时 Demo 后，从输出文件重新解析每个贴纸槽位的最终 wear、scale、rotation、offset X/Y 和 schema。
2. 解析结果按“玩家 XUID + 枪械 definition + 实体 handle + 五个逻辑槽位”回传控制面板，并附带持有与活动武器 tick 范围。
3. 保留原位模式使用这份最终 Demo 数据，并按有效 schema 选择真正的 VMDL 投影面；自定义模式继续以当前编辑参数为准。
4. 从保留模式切换到自定义或直接拖拽时，先把已解析的实际点投影到自定义槽位的材质坐标，同时承接实际 scale 和 rotation，避免切换模式的第一帧跳位。

同一玩家的同一枪型可能在 Demo 中出现多个实体，不同回合或拾取的枪械可以携带不同原贴纸变换。重建器不再把它们强行合并成一份数据；回传结果保留每个武器实体的持有 tick，以及 `m_hActiveWeapon` 表明它真正出现在第一人称画面中的 tick 范围。控制面板优先用当前 Demo tick 匹配活动武器范围，范围重叠时选择更晚成为活动武器的实体；只有缺少活动记录时才回退到持有范围。只有同一实体自身在时间轴上出现互相冲突的变换时，才对该槽位回退到预设图，避免冒充真实位置。

## 验证与验收

- 自动测试覆盖 AK/AWP 新旧模型五槽实时属性和临时 Demo 五槽 schema，防止只测试第一个槽位（schema 原本就是零）而漏掉其它槽位。
- Rust 回读测试覆盖显式零、非零、缺省、`-1` 以及 raw/initial 不同值的情况。
- 使用用户复现的原 Demo 完成五槽自定义位置重建并重新解析：7 个 AK 实体、35 个槽位全部可用，schema 均为 `[0, 1, 2, 3, 1]`，第五槽保留校准偏移。独立检查器另外确认这 7 个实体的 55 次状态快照均包含正确 schema。该结果证明序列化与回读一致，不能代替游戏内视觉验收。
- Rust：24 通过、4 个需外部夹具的测试未执行；本次真实贴纸 Demo 已另行实测。C++ 完整回归通过，包含已安装客户端的仅饰面材质证据校验、贴纸预览和五槽属性检查。中英文 Release DLL 均构建成功。

- 必须从原 Demo 重新生成临时 Demo，旧产物不包含回传结果。
- 生成完成并自动加载后，预设槽位的画布位置应与实际枪上的相对位置一致，包括原 Demo 中已有重合的情况。
- 从预设模式点选或拖拽任意贴纸后，其他槽位不应移动；当前槽位在进入自定义时不应先跳到标准预设点。
- 如需消除来源自由摆放的影响，对当前使用的槽位分别点击“使用预设位置”，再从原 Demo 重新生成；单纯关闭自定义开关会有意保留来源位置。
