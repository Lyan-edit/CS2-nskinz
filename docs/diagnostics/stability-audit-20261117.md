# 稳定性与性能审查（2026-11-17）

基于 v0.7.5-beta 的本地修复。此次未发布 GitHub Release，未启动 CS2 或 HLAE。版本号保持不变，交付文件名增加 `stability` 以区别已发布附件。

后续集成到 [v0.7.5 正式版](../releases/v0.7.5.md)。以下记录和 DLL 摘要对应首次本地稳定性测试件；正式版本的附件及摘要以 Release 为准。

## 已修复的问题

| 风险路径 | 修复前证据 | 本次处理 | 验证结果 |
| --- | --- | --- | --- |
| 配置并发读取 | `SnapshotConfig()` 与 `ConfigRevision()` 分开读取，压力测试出现 4 次内容/版本错配 | 独立的短配置锁原子发布不可变文档和版本；旧读者继续持有有效快照 | 5,000 次发布的并发回归中错配为 0 |
| 配置重复复制 | 维护轮询复制配置、贴纸数组和刀配置；部分帧级工厂检查也复制整份配置 | 只在文档或版本变化时重新生成实时配置，其他轮询复用；HUD 使用源快照中的刀配置 | 64 项配置微基准：复制约 684.75 ns/次，复用约 22.76 ns/次 |
| UI 遮挡、最小化和设备失败 | 注入 `DXGI_STATUS_OCCLUDED` 后，真实面板循环一秒空转 21,655 次；错误的 `Present` 也没有等待或恢复 | 最小化时停止绘制；遮挡时等待 100 ms；设备失败释放图形资源，保留编辑内容和重建任务，允许 Insert 重试 | 遮挡测试降至一秒 11 次；设备失败后重新创建并成功输出画面 |
| UI 缩放/调整窗口 | 原路径未解绑 immediate context 持有的 backbuffer，且忽略 `ResizeBuffers` 和 render-target 创建失败 | 窗口消息仅记录待调整状态；绘制循环先解绑、释放旧目标，再检查调整与创建结果 | 实际调整窗口后，backbuffer 与客户区尺寸匹配，画面输出通过 |
| 损坏 VPK 的内存突增 | 声明 16 MB、实际只有文件头的 VPK，读取失败前仍分配 16 MB | 按已打开文件的长度校验 offset/length，再分配；相同检查用于目录和模型资源读取；VPK 字符串限定在 tree 范围及 4,096 字符内 | 原调用路径的截断文件测试改为分配 0 字节；有效 inline entry、越界和溢出测试通过 |
| 异线程帧回调 | 线程不匹配时只记录日志，仍改变帧计数并继续进入运行时；生产回调的隔离测试失败 | 非所属线程仅转发原函数一次，提前返回，不触碰游戏线程状态和配置缓存 | 原回调隔离测试通过，无游戏原生调用 |

微基准比较的是同一离线测试程序中复制与缓存读取的开销，不能换算成游戏帧率收益。正常可见面板继续使用原有垂直同步；未提高饰品维护轮询频率，未新增渲染线程磁盘写入。

## 验证

- 中英文 Release DLL 编译成功。
- 完整 C++ 回归 61 个顶层命名测试组通过（部分测试组内含多组用例）。本机 CS2 2000943 的 11 个换图 hook 位置均唯一匹配。
- Rust 解析器：42 通过；重建器：30 通过，6 个依赖外部录制的用例仍按原设置忽略。本轮没有重新执行真实 Demo 重建矩阵。
- 11 个真实面板场景通过：遮挡、调整窗口、Present 失败、设备初始化失败、构造失败、部分资源失败、标准面板、刀饰面、手套饰面、未知模型、挂件。
- 中英文共 6 个隔离 DLL 加载场景，以及 WARP/DXBC 渲染与三次设备重建通过。
- 中英文目录文本、系统 DLL 依赖、内嵌重建器及全部 19 份雷达资源校验通过。
- Inferno Water 固定标准 SHA256 仍为 `7efdf576940999d6d9c1453f50081c4ced02b7b478255f0a49c804227371b2a7`。

离线针对性回归：

```powershell
build/Release/nSkinzCS2.Tests.exe --stability-only
```

UI 故障回归使用 `nSkinzCS2.UiPreview.exe --occlusion-probe`、`--resize-probe`、`--fail-present-once`。这些程序只启动独立测试面板，不连接游戏。详细前后日志、编译日志、资源验证结果和 SHA256 清单位于 `build/stability-audit-20261117/`。

## 验证边界

这是一轮入口及主要风险路径的审查和有针对性的修复，并不等于所有缺陷已经清零。游戏内帧时、长时间播放/反复 seek、多种显卡驱动的真实设备丢失尚未实测；图形故障使用受控注入验证。现有签名和实体代际保护仍是更新后运行的前提。本次未执行第三方依赖的全量安全数据库扫描或长期模糊测试。
