# DLL 加载 OK，但 Insert 无法打开面板

日期：2026-10-28；2026-10-29 纳入 [v0.6.6-beta](../releases/v0.6.6-beta.md)。以下保留基于 v0.6.5 的诊断和本地测试记录。

## 日志能确认的事实

用户提供 `nSkinzCS2 (6).log` 与 `nSkinzCS2.ui (6).log`。前者显示 CS2 `2000935`／Patch `1.41.9.2`，HLAE 目录为 `hlae_2_192_10`；DLL、物品目录、运行时工作线程及外置面板进程均已启动。

UI 日志在目录载入和状态初始化后立即出现：

```text
UI thread raised a C++ exception and was disabled.
```

没有后续的 `UI thread started in lazy-init mode`。结合源码可确定：异常发生在 `WindowController` 构造阶段，尚未进入 Insert 监听循环。旧版捕获异常后将线程永久停用，但外置宿主仍等待 CS2 结束，因而反复按键不会重新创建面板。

控制台的 OK 表示 DLL 加载成功，不代表异步启动的 UI 已经健康。

**旧版主动丢弃了 `exception.what()`，这两份日志无法还原具体异常类型、触发文件或目录。** 工坊扫描是构造函数中的可选外部 I/O 路径，本次将其隔离，但不把它宣称为已从原日志证实的唯一触发源。

## 修改

- 控制器构造不再扫描所有 Steam／工坊目录。打开地图页时按需扫描；启用地图替换后保存或应用配置时，也会先做受保护的扫描，以保留原有元数据补全／辅助地图迁移行为。
- 工坊扫描使用非抛出文件状态与迭代接口，按库隔离异常，保留健康库的结果，并将路径错误显示为诊断。Steam 库路径及包名显式使用 UTF-8；损坏包不能抢占正常包的 addon 名称。
- UI 捕获 C++ 异常时记录阶段和具体消息，等待释放并重新按 Insert 后再试；不在后台持续重建／抛异常。
- 分别跟踪 ImGui 上下文、Win32 和 DX11 后端的初始化状态，允许中途失败后正确释放已创建的资源。
- 临时窗口在初始化失败清理时不再向 Insert 监听线程投递退出消息。普通设备初始化失败也能留在监听循环中重试。
- 配置路径支持长模块路径；中文字体从实际 Windows 目录解析，缺失／不可读候选字体不通过文件状态异常终止 UI。
- 默认 T／CT 手套和挂件的临时 Demo 路径、前一轮刀具模式分流均保留；没有改动内嵌 Demo 重写器。

## 验证

`nSkinzCS2.UiHarness.vcxproj` 编译相同的真实 UI 实现，不加载 CS2 或 Hook。专用宏仅用于测试程序的异常注入、重试触发和 DX11 渲染帧导出，不进入发行 DLL。

`tools/verify_ui_startup.ps1` 的四个场景均返回 0 并生成真实界面 PNG：

| 场景 | 验证 |
| --- | --- |
| 正常启动 | 构造、D3D11、中文字体及界面绘制 |
| 构造阶段抛出 C++ 异常一次 | 记录具体异常，重新构造后成功绘制 |
| 已创建部分资源后抛出 C++ 异常一次 | 清理上下文／设备／窗口，重建后成功绘制 |
| 设备初始化返回失败一次 | 不退出监听循环，同一控制器重试后成功绘制 |

报告及每次日志位于 `build/ui-startup-fix-20261028/ui-regression/`。测试没有注入真实键盘事件，验证的是失败恢复机制及实际界面绘制，不能等同于已经在报告用户的电脑上验收 Insert。

坏目录、缺失库、非目录条目、损坏 VPK 和 Unicode／emoji 包名的专项回归通过；健康样本仍可被扫描。该样本不声称复现了用户未记录的具体异常。完整原生回归也已通过，包括现有饰品、工坊地图和雷达功能。

最终中英文 DLL 通过 6 项隔离加载、便携导入／中文资源及离屏 WARP 检查；已确认内嵌重写器未变，并检查测试故障注入字符串没有进入 DLL。附件摘要见本地 `build/ui-startup-fix-20261028/artifact-verification.json`。

## 使用与后续诊断

使用本地 `ui-startup-fix` 后缀的新 DLL，先退出并重新启动 CS2／HLAE，只加载一个语言版本，避免旧的失效外置宿主继续占用当前会话。

- `build/Release/Lyan_nskinz v0.6.5 EN ui-startup-fix.dll`
- `build/Release/Lyan_nskinz v0.6.5 zh-CN ui-startup-fix.dll`

加载后按 Insert。若初始化发生可恢复失败，释放再按一次可重试；`nSkinzCS2.ui.log` 会记录构造／渲染阶段及具体异常消息，不再只有“C++ exception”一句话。
