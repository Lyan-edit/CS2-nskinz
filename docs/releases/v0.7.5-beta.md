# nSkinzCS2 v0.7.5 Beta

2026-11-16 · Beta prerelease / 预发布版

## 中文

- 修复 0.7.4 工坊换图时 `manifest=0`，导致整条地图替换链未安装的问题。更新当前引擎资源清单路径特征，恢复唯一匹配；路径参数仍按已验证的 R8 ABI 处理。
- 运行时与离线回归共用全部 11 个地图钩子入口的定位器。提供 `--cs2-root` 的完整回归现在也会检查这些入口；新增 `--map-remap-only` 定向检查。
- 保留严格唯一匹配与原子安装、固定 Inferno Water 透明雷达、此前 fixed8 临时 Demo 修复及 19 项多普勒／伽马多普勒标签。
- 保持 CS2 `2000943 / 1.41.9.7`、SourceRevision `11228971` 和 HLAE `2.193.0 / AfxHookSource2 0.42.0` 兼容基线。
- 更新 Beta 版本标识、首页封面及真实控制面板图片，提供中英文 DLL、完整包、完整对应源码和 SHA256。

验证：同一安装文件上已复现旧特征零匹配，修复后 11 个入口全部唯一匹配；完整 C++ 回归、解析库 42 项及重写器 30 项普通回归、中英文 DLL 隔离加载与内嵌资源检查通过。默认手套跨 Demo 验证沿用同一重写器已通过的 4 份录制／28 名玩家／158 次独立跳转证据。

**这是 Beta 预发布版。** 本轮未启动 CS2／HLAE，也未实际加载工坊地图；游戏内换图效果仍待验证。
重启已加载旧 DLL 的进程，仅加载一个语言版本。打开 Demo 后，在地图页选择目标地图并点击智能应用，等待重载。
详细证据见[地图替换根因与回归记录](../diagnostics/map-remap-manifest-20261116.md)。

## English

- Fix Workshop map replacement being disabled by a missing manifest hook match in v0.7.4. Update the exact current-engine signature while retaining the verified R8 path argument ABI and strict unique matching.
- Share the runtime locator for all 11 map hook sites with offline tests. Full regressions with `--cs2-root` now audit this chain; `--map-remap-only` provides a focused check.
- Retain atomic hook installation, locked transparent radars, the fixed8 Temporary Demo repair and all 19 knife Doppler/Gamma Doppler variant labels.
- Keep the CS2 `2000943 / 1.41.9.7` and HLAE `2.193.0 / AfxHookSource2 0.42.0` compatibility baseline. Refresh the homepage artwork and ship both DLL languages, complete corresponding source and SHA256 checksums.

Validation reproduces zero matches with the original signature and exactly one match for each of the 11 repaired map hook sites. Full C++ regressions, 42 parser tests, 30 ordinary rewriter tests, isolated DLL loading and embedded-resource checks pass. The unchanged rewriter retains its four-recording, 28-player and 158-independent-seek default-glove validation evidence.

**Beta prerelease:** CS2/HLAE were not started and in-game Workshop map acceptance remains pending. Restart the process carrying the old DLL, load one language only, open the Demo, then use the map's Smart Apply button and wait for reload. The stable latest release remains v0.7.4.
