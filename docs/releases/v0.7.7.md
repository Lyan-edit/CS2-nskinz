# nSkinzCS2 v0.7.7

2026-11-21 · Release / 正式版

## 中文

- 新增独立的“地图材质：打蜡反光”应用项，位于原地图页底部。DLL 内嵌 1450 项已编译材质，覆盖 Ancient、Anubis、Cache、Dust2、Inferno、Mirage、Nuke、Overpass；玩家无需另下 VPK 或安装编译器。Mirage Water / Inferno Water 可使用对应基准，其它未知工坊变体不自动匹配。
- 材质应用只提交当前材质设置并重载 Demo，不连带应用其它暂存饰品，也不要求 XUID。缓存按包内容和地图隔离，自动核对并修复损坏文件。解包、哈希与写盘不进入渲染回调。恢复按钮关闭材质重定向并重载；引擎仍缓存旧材质时需要重启。
- 改为一个中英文共用 DLL，默认简体中文。“设置 → 语言 / Language”即时切换并自动保存。语言偏好独立于饰品配置，中英文目录的物品 ID 和兼容范围一致。保留原有 UI 布局、配色、控件与预览。
- 修复暂停 Demo 时重载命令一直等待数据更新阶段的问题。已确认的游戏帧线程可在 FrameStart / RenderPass 派发队列，不必先手动恢复播放；命令只派发一次，不在后台线程调用引擎。
- 补上外部面板的输入交接：Insert 收起或关闭时，仅在面板拥有焦点的情况下将焦点还给对应 CS2 窗口；F8 按到面板时关闭面板并交还原始按键。不会抢其它前台应用的焦点，不修改 ReShade 配置。材质区显示 DLL 实际应用状态，ReShade 效果独立控制。
- 保留枪械、刀、默认 T/CT 与其它手套、五槽贴纸热修，挂件仅临时 Demo 重建，工坊换图与固定透明雷达，以及持枪者 XUID、HUD 名称、独立应用和空会话启动规则。
- 更新首页 0.7.7 封面和真实原生面板截图。保留必要第三方许可证与署名。

升级时完整退出旧 CS2/HLAE，再加载 `Lyan_nskinz-v0.7.7.dll`，不再区分中文与英文附件。配置仍为 `nSkinzCS2.json`，语言偏好为 `nSkinzCS2.settings.json`。每次启动从空应用会话开始，历史保存配置不会自动应用。

验证覆盖：62 组完整原生回归；暂停无数据包重载、F8 输入及焦点交接的红绿回归；8 地图 1450 材质解包/校验/缓存复用/损坏修复；1450 材质与 45,376 个 shader 参数及纹理引用核对；本机 11 个地图签名唯一匹配；中英文目录 ID 与兼容范围、真实 UI 截图及故障恢复、独立加载及离屏渲染。对应客户端为 CS2 `2000948 / 1.42.0.0`，SourceRevision `11259529`。

用户已在前述测试版反馈效果生效。本次发版构建未启动 CS2/HLAE；自动测试和文件命中计数不能代替不同 Demo、ReShade 组合、长时间播放及 GPU 帧耗验收。

## English

- Add independent waxed-reflection map materials below the existing map editor. The DLL embeds 1,450 compiled materials for eight base maps; no separate VPK or compiler download is required. Known Mirage Water / Inferno Water variants use their corresponding base map; unknown Workshop variants do not auto-match.
- Apply only the material item and reload the current Demo, without submitting staged cosmetics or requiring an XUID. Verify and repair isolated versioned caches outside render callbacks. Restore removes redirects and reloads; cached engine resources may require a restart.
- Ship one DLL with Simplified Chinese as default and instant, persistent English switching under Settings. Language preferences do not apply cosmetics. Preserve the existing UI style, layout and previews; localized catalogs retain identical item IDs and compatibility data.
- Fix paused Demo reloads waiting for entity data updates. Dispatch queued playback commands once on the confirmed game frame thread, including frame-start/render callbacks, without engine calls from the worker thread.
- Return focus to the matching game window when closing the foreground panel; hand an F8 press received by the panel back to the game. Leave unrelated foreground applications and ReShade configuration untouched. Show applied DLL-material state separately from staged edits and independently controlled ReShade effects.
- Retain all live gun/knife/glove/five-slot sticker routes, charm-only Temporary Demo reconstruction, Workshop maps, fixed transparent radars, holder targeting, HUD names and isolated per-item applications. Refresh homepage artwork and the real native panel capture.

Restart CS2/HLAE before loading `Lyan_nskinz-v0.7.7.dll`. There are no separate language binaries. Editor settings remain `nSkinzCS2.json`; language uses `nSkinzCS2.settings.json`. Each process starts with an empty applied session.

Validation covers 62 native test groups, red/green paused-command and input-handoff regressions, every embedded material and cache repair, localized catalog identity, 11 unique map hook sites, real UI/recovery captures, isolated loading and offscreen rendering. Inspected client: `2000948 / 1.42.0.0`, SourceRevision `11259529`. The user reported successful behavior in the preceding test build; this release build did not start CS2/HLAE. Cross-recording rendering, ReShade combinations and GPU frame times still require acceptance testing.
