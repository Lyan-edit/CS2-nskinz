# nSkinzCS2 v0.7.3 Beta

2026-11-10 · Prerelease / Beta 预发布

## 中文

- 修复临时 Demo 重建后的场景资源组索引失效。饰品字段改变文件长度后，现在同时更新 FileInfo 与 SpawnGroups 的文件头位置，覆盖原始命令、压缩命令和表被删除的情况。
- 新增独立的容器检查：按真实命令边界核验两个索引，拒绝陈旧、越界或截断的文件；检查继续越过 DemStop，覆盖位于它之后的资源组和文件信息。校验失败不自动加载生成文件。
- 保留 v0.7.2 的各项独立智能应用、刀／手套按当前实际型号筛选饰面，以及默认 T／CT 手套只走临时 Demo 重建的限制。
- 更新中英文 DLL、对应完整源码、首页版本封面及真实控制面板截图，保留固定 Inferno Water 透明雷达标准。

真实 Ancient 复现中，旧产物资源表移动 25,192 字节后，头部仍指向原位置。使用相同请求重建后，新旧文件大小均为 410734082 字节，仅索引字段中 3 个字节变化，饰品数据全部相同。另一个独立录制也发现同类旧索引问题。证据及实现见[诊断记录](../diagnostics/demo-header-spawn-groups-20261109.md)。

本次验证以本机安装的 CS2 `2000942 / 1.41.9.6` 为基线：29 项普通 Rust 回归、6 个真实文件索引用例、完整 C++ 回归、隔离 DLL 加载和内嵌资源检查通过。4 项额外饰品外部夹具未在本轮重跑；真实头部索引夹具单独执行。没有启动 CS2 或 HLAE，游戏内加载仍需实测，因此本版标记为 Beta。

升级方法：退出仍加载旧 DLL 的进程，只加载一种语言版本，再从原始 Demo 重新生成临时 Demo。既有坏文件不会因为替换 DLL 自动改写。保存／加载只管理编辑器配置，需要使用各区域对应的应用按钮。

## English

- Fix stale SpawnGroups offsets after Temporary Demo entity rewrites change the file size. Relocate both FileInfo and SpawnGroups header indexes for raw/compressed output; clear a removed table's index.
- Add an independent container gate that checks command boundaries and header indexes, rejects stale/out-of-range/truncated data, and scans resource records after DemStop. A failed check prevents automatic loading.
- Retain independent per-item Smart Apply, current-model Finish-only filtering, and reconstruction-only handling of default T/CT gloves.
- Refresh both language DLLs, complete corresponding source, homepage cover and unmodified native panel capture. Keep the locked Inferno Water radar.

The reproduced Ancient output retained an index 25,192 bytes before the actual resource table. With the same rewrite request, old and corrected outputs have identical sizes and differ at only three bytes in the header index; cosmetic data is unchanged. A separate recording also exposed the stale-index defect.

Validation uses the installed CS2 `2000942 / 1.41.9.6` baseline: 29 ordinary Rust tests, six real-file header fixtures, full native regressions, isolated DLL loading and embedded-resource checks pass. Four additional external cosmetic fixture tests were not rerun for this release; the real header fixture was run separately. CS2/HLAE were not started, and in-game loading acceptance remains pending. This release is marked **prerelease**, leaving v0.7.2 as GitHub's stable latest.

Restart the process carrying the old DLL, load one language only, and regenerate Temporary Demos from the original recording. Replacing the DLL does not repair existing generated files.
