# nSkinzCS2 v0.6.4 — Fixed radar references and knife HUD labels

Release date / 发布日期：2026-11-03。**Stable release / 正式版**。

## 中文说明

本次发布汇总当前刀具 HUD、贴纸预览、控制面板及透明雷达修复。

- **固定 Inferno Water 雷达标准**：采用用户确认的 720×720 真透明图，不再根据黑底容差、道路恢复或后续资源重扫重新生成。文件与校验值锁定，未经用户明确授权不替换；文档中的棋盘格不进入游戏纹理。
- **内嵌地图雷达参考库**：收录 19 种已复查的纹理版本，相同版本加载相同参考图，不依赖开发者电脑上的临时文件。普通记录按资源路径、长度及源指纹匹配；未收录版本保留原通用处理。已锁定的 Inferno Water 标准在源版本变化时保持原图并记录差异。
- **减少雷达压缩暗边**：参考图通过 RGBA8888 原生无损路径编译。固定图编译后独立解码，与原标准的 RGBA 像素差异为 0；处理和编译仍在独立控制面板进程中完成。
- **刀具右侧 HUD 完整名称刷新**：材质和原生名称缓存更新后，在已核验的 HUD 原生回调中更新当前武器图标的完整本地化名称，避免保留旧饰面名。请求按完整句柄、刀型、归属、配置和场景代次核对，每份配置／图标只提交一次。
- **贴纸预览与写入使用相同投影槽**：区分显式 schema `0` 与缺省／`-1`。保留原位模式从重建产物回读真实五槽变换，按玩家、枪型、实体及活动 tick 选择预览；“使用预设位置”明确写入预设起点。
- **面板字段说明与品质汉化**：“配置名称”管理左侧配置列表，“游戏内名称标签”修改物品名称。保留会写入经济物品字段的品质选项，汉化 15 项并支持中英文搜索；默认手套重建需要的特殊品质规范化保持不变。
- **路径分工保留**：刀具“模型＋饰面”仅走临时 Demo，“仅饰面”仅走当前 Demo 热修；默认 T／CT 手套与挂件仍仅走临时 Demo 重建。其它已有枪械、刀、手套、挂件及地图功能继续保留。
- 同步 v0.6.4 封面和当前真实控制面板截图，保留源码与附件卫生检查。

### 使用方法

1. 退出仍加载旧 DLL 的 CS2／HLAE，启动后只加载一个 v0.6.4 语言版本。
2. 刀具“仅饰面”：在当前 Demo 中选择涂装，点击“更新”；此模式不改变刀型。
3. 刀具“模型＋饰面”、默认手套或挂件：从原始录制重新生成临时 Demo。贴纸需要读取最终变换时也重新生成，旧临时产物不会自动补齐回传数据。
4. 工坊地图使用来源雷达后，点击“更新”并重新加载 Demo。已登记参考图不使用黑底容差／道路恢复滑轨重新生成；背景不透明度仍可单独调节，默认完全透明。
