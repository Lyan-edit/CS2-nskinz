# nSkinzCS2 v0.7.6

2026-11-21 · Release / 正式版

## 中文

- 枪械饰面、刀的仅饰面与换刀型、手套仅饰面与换模型（含默认 T/CT 手套）、五槽贴纸统一使用当前 Demo 的热修改路径。按当前持枪者 XUID 应用，保留右侧 HUD 名称同步。
- 挂件替换、新增、清除和位置参数使用临时 Demo 重建。暂停尚未完成的挂件热修生成流程，保留源码与诊断进度。重写计划和执行入口同时过滤为挂件，避免把刀、手套、枪械饰面或贴纸写入新 Demo。
- 恢复创意工坊地图、播放命令桥和透明雷达。地图按钮只重载当前 Demo，不要求配置饰品 XUID；保留 19 个雷达参考版本及固定 Inferno Water 标准。
- 修复历史配置自动启用：每次加载 DLL 创建空的进程应用会话。保存/加载只编辑配置，每个智能应用按钮只提交当前项。关闭并重新打开控制面板可保留本次明确应用的项目，重新启动 CS2 后不会自动启用历史项目。
- 保留五槽贴纸编号、选中槽黄色高亮、具体枪型预览、微调滑轨和蓝色挂件预览。
- 同步中英文 DLL、源码、首页封面版本与当前真实控制面板截图，保留导入组件的原始许可证与署名。

使用 `nSkinzCS2.json` 保存编辑器配置，进程应用文件为 `nSkinzCS2.session-<CS2 PID>.applied.json`。旧正式版配置可以继续编辑；测试版 `nSkinzCS2.live-test.json` 可备份后复制为正式配置名。本次不会导入历史 `.applied.json` 自动应用。已在本会话点击应用的项目会随回跳、换图或挂件 Demo 重建保持；源 Demo 原本的饰品属于录制内容。

升级时完整重启 CS2/HLAE，只加载一种语言的 v0.7.6 DLL。通过 HLAE、带 `-insecure` 播放离线 Demo。挂件从原始 Demo 生成新文件，原文件不覆盖；临时 Demo 页只处理挂件。旧 Demo 尝试录制中没有的新模型仍可能失败，保留已知失败记录与保护。

本次验证：热修/HUD/当前持枪者及独立应用回归、会话隔离、稳定性、日志、播放桥、双语独立加载及离屏渲染、真实控制面板截图。真实源 Demo 的仅挂件重建通过 31,812 条校验，其中 153 条新增快照记录，枪械饰面/刀/手套/贴纸重写均为 0；源文件摘要未变。地图 11 处 Hook 签名唯一匹配，19 个安装雷达版本及固定标准通过原生编译回归。本机离线检查所用客户端为 CS2 `2000948 / 1.42.0.0`，SourceRevision `11259529`（Nov 19 2026）。

用户已在测试版本确认刀、手套和 HUD 正常。本次发布构建未启动 CS2/HLAE；自动测试和离线重建不能替代不同 Demo 的画面、长时间播放及帧时验收。

## English

- Guns, all knife modes, all glove modes including stock T/CT gloves, and all five sticker slots use live changes in the current Demo. Rules target the current holder, with right-side HUD name synchronization retained.
- Charm replacement, addition, removal and placement use Temporary Demo reconstruction exclusively. The unfinished live charm creation research is preserved and suspended. Both the rewrite planner and executor filter out every live cosmetic.
- Restore Workshop maps, the playback bridge and transparent radars. Map Apply reloads the current Demo without requiring a cosmetic XUID. Keep all 19 reviewed radar versions and the locked Inferno Water standard.
- Start each injected process with an empty applied session. Saved settings remain in the editor until that item's Apply button is pressed. Reopening the panel preserves explicitly applied items in the same process; restarting does not replay historical applications.
- Retain weapon-specific five-slot sticker previews, yellow selected-slot highlighting, fine controls and the blue charm preview. Refresh bilingual release artwork and the actual native panel capture.

Editor settings use `nSkinzCS2.json`; process applications use `nSkinzCS2.session-<CS2 PID>.applied.json`. Back up and rename a local test editor file if migrating. Restart CS2/HLAE and load one language only. Charms regenerate from the original recording without overwriting it. Older-Demo model compatibility remains guarded and cannot be guaranteed for every recording.

Local checks cover live/HUD/holder routing, independent applications, process sessions, playback dispatch, stability, logging, bilingual loading and native UI rendering. A real-Demo charm-only rewrite verified 31,812 records, including 153 newly materialized snapshot records, with zero gun finish/knife/glove/sticker rewrites and an unchanged input hash. Eleven map hook sites matched uniquely; 19 installed radar versions and the fixed standard passed native compilation. The inspected client is `2000948 / 1.42.0.0`, SourceRevision `11259529`.

The user accepted knife, glove and HUD behavior in the preceding test build. No CS2/HLAE process was started for this release; rendered results across other recordings, long-session playback and gameplay frame times still require acceptance testing.
