# nSkinzCS2 v0.6.6 — Complete cosmetic catalogs and panel recovery

Release date / 发布日期：2026-10-30. **Stable release / 正式版**。

## 中文说明

在 v0.6.6-beta 的刀具模式分流和面板恢复基础上，修复手套目录误分类、廓尔喀刀菜单漏项及纪念品挂件继承模型信息缺失。

- **手套补齐 22 款**：运动手套 7 款（包括“隐知”，ID `1417`）、驾驶手套 8 款、专业手套 7 款。旧代码按 `>=10000` 及旧命名前缀识别手套，新系列使用低 ID，因而误归入枪皮。现在以游戏定义的精确型号／涂装关系和库存图标为准，保留旧目录兜底，矛盾证据不随意放行。
- **廓尔喀刀补入菜单**：底层已支持 Kukri（`526`），但静态名单漏列。本版补齐刀型、模型／图标信息及其 12 个涂装组合，并增加防止名单再次落后于底层支持的回归。
- **挂件模型继承补全**：61 个纪念品挂件从具名 `base` 继承模型。其 ID 原本已在列表中，本次补全模型元数据，不宣称此前 61 个全部无法使用。缺失或循环基类不猜测模型。
- **全目录独立核对**：英文、简体中文分别直接对照游戏 KeyValues、VPK 和 C++ 目录快照，检查型号、可见选项、兼容组合及模型元数据。现有支持范围内没有其余漏项。
- 保留 **模型＋饰面只走临时 Demo**、**仅饰面在当前 Demo 内热修贴图**的刀具分流；默认 T／CT 手套和挂件仍只走临时 Demo。内嵌重写器保持不变。
- 保留面板 C++ 异常后的 Insert 重试、详细异常日志、按需且隔离的工坊扫描及部分图形资源清理修复。
- 首页封面、真实面板截图和下载链接同步到 v0.6.6；发版图片检查继续生效。

### 目录核对结果

| 模块 | 范围 | 结果 |
| --- | --- | --- |
| 常规枪械 | 34 把，1,471 个型号／涂装组合 | 无漏项／额外错误组合 |
| 市场刀型 | 20 种，556 个型号／涂装组合 | 无漏项，含 Kukri |
| 手套 | 94 个真实涂装 | 型号全部对应，无误入枪皮 |
| 贴纸 | 11,642 个选项（含 0 项） | 无漏项 |
| 挂件 | 143 个非零选项 | 无漏项，模型信息全部可解析 |

手套原始目录另有 0 和 Workshop 占位项，共 96 项；挂件加“无”项共 144 项。Zeus 电击枪（31）及其 7 个涂装仍在既有常规枪械模块支持范围之外，本次没有仅添加菜单就宣称接通其刷新、贴纸、挂件或重建链。

### 使用

1. 退出并重启 CS2／HLAE，备份需要的配置，只加载一个语言版本的 v0.6.6 DLL。
2. 启动流程会重新生成目录快照；运动手套现在可选“隐知”等新涂装，刀型中可选廓尔喀刀。
3. 默认 T／CT 手套、刀具“模型＋饰面”和挂件配置完成后，从原始录制重新生成临时 Demo。更换 DLL 不会自动改写旧临时文件。
4. 刀具“仅饰面”选择贴图后点击“更新”，在播放中的原始／临时 Demo 内应用。
5. 按 Insert 打开面板；可恢复初始化失败后释放按键并重新按一次。查看 `nSkinzCS2.ui.log` 中的具体阶段和异常信息。

### 验证与兼容边界

- 57 项完整原生回归通过；全部 94 个手套涂装生成默认 T／CT 双队伍请求并通过计划校验，型号不符仍被拒绝。
- 双语独立目录核对通过。回归覆盖低 ID 手套、未来高 ID 枪皮、旧前缀、纯图标组合、名称碰撞、矛盾证据、VPK 手套图标、挂件直接／嵌套／缺失／循环基类。
- 四项真实面板启动／异常恢复场景、中英文编译、便携导入／中文文本、隔离加载及离屏 WARP 渲染检查通过。

目录证据来自本机 CS2 `2000938`／Patch `1.41.9.3`。**本次目录核对不等于完成该客户端全部原生地址适配**；原生兼容证据仍沿用 CS2 `2000935`／Patch `1.41.9.2`／Steam Build `26144732`，HLAE `2.192.8`／AfxHookSource2 `0.41.8`。缺失或不唯一的必要签名继续阻止相应功能。

目录、请求计划和加载检查不等于逐款 CS2／HLAE 画面验收。面板测试不注入物理键盘事件；报告用户的 Insert 行为、饰品实际渲染和游戏帧时间仍需实机确认。没有新的逐款画面或帧时间基准。

详见[目录根因、22 个漏项及审计记录](../diagnostics/catalog-coverage-20261030.md)、[面板启动诊断](../diagnostics/ui-startup-exception-20261028.md)和[刀具模式分流](../development/knife-mode-routing-live-finish-20261028.md)。

## English notes

The stable release restores 22 glove finishes (7 Sport, 8 Driver, 7 Specialist), including Sport Gloves | Occult (`1417`). Modern glove paints share the firearm ID range; exact game definitions and inventory icons now determine their model associations instead of numeric ranges. Conflicting evidence remains blocked.

Added the already-supported Kukri Knife (`526`) to the menu with its visual metadata and 12 finish combinations. Completed inherited model metadata for 61 souvenir keychains; their IDs were already listed, so this is not a claim that all 61 were previously unusable.

Independent English/Chinese audits pass for 34 firearms / 1,471 pairs, 20 market knives / 556 pairs, 94 glove finishes, 11,642 sticker options including zero, and 143 nonzero keychains. No remaining omissions or incorrect pairs were found within that scope. Zeus (31) and its 7 paints remain outside the existing firearm module.

Retains beta knife-mode routing and panel recovery: Model + Finish, default T/CT gloves and keychains use Temporary Demo reconstruction; Finish-only hot-updates the current knife texture in the playing source/generated Demo. UI failures log their phase/message and can retry after releasing and pressing Insert. The embedded rewriter is unchanged.

Restart CS2/HLAE, load one language DLL and regenerate reconstructed items from the original recording. Startup refreshes the catalog snapshot. Existing generated files are not automatically repaired.

57 native tests, both language builds/audits, four native UI startup/recovery cases, portable imports/localization and isolated loader/WARP checks pass. All 94 glove finishes produce both T/CT rewrite requests with validated models. These checks do not certify per-item gameplay rendering, the reporting user's physical Insert key or frame-time improvements.

Catalog data was audited against installed CS2 `2000938` / Patch `1.41.9.3`. This is not comprehensive native-offset certification for that client. The native compatibility evidence remains CS2 `2000935` / Patch `1.41.9.2` / Steam Build `26144732`, HLAE `2.192.8` / AfxHookSource2 `0.41.8`; required signatures remain guarded.
