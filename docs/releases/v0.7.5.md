# nSkinzCS2 v0.7.5

2026-11-17 · Stable release / 正式版

## 中文

- 修复配置内容与版本号分开读取时的竞态，改用成对发布的不可变快照。实时派生配置仅在配置变化时更新，减少维护轮询、手套工厂检查及刀具刷新中的重复复制。
- 修复控制面板被遮挡、最小化或 `Present` 失败时可能持续空转的问题。显卡设备异常后保留编辑内容和后台重建任务，通过 Insert 重建图形资源；窗口缩放先解绑旧 backbuffer，再检查调整和渲染目标创建结果。
- VPK 读取在分配内存前检查文件中的实际范围，并限制目录字符串范围与长度，减少损坏文件引起的内存突增。帧回调遇到异线程时仅转发原函数一次，不再继续修改游戏线程状态。
- 包含 0.7.5 Beta 的工坊换图 manifest 特征修复。运行时与离线回归共用全部 11 个地图入口的定位器，保留严格唯一匹配与原子安装保护。
- 保留既有功能分流、HUD 名称同步、默认 T/CT 手套临时 Demo 重建、五槽贴纸与挂件、fixed8 Demo 修复、19 项多普勒／伽马多普勒标注和固定透明雷达。
- 更新正式版本标识、首页封面和真实控制面板截图，提供中英文 DLL、完整包、对应完整源码和 SHA256。

验证：完整 C++ 回归、解析器 42 项、重建器普通测试 30 项、12 个真实面板场景、中英文 DLL 隔离加载及离屏渲染检查通过。另有 6 个依赖外部录制的重建器用例按原设置跳过；本次没有重新执行真实 Demo 重建矩阵。内嵌重建器及 19 份雷达参考图均验证保持一致。

本机兼容基线为 CS2 `2000943 / 1.41.9.7`、SourceRevision `11228971`，HLAE 兼容记录为 `2.193.0 / AfxHookSource2 0.42.0`。本次未启动 CS2 或 HLAE；实际换图、游戏帧时及长期播放/跳转仍待实测，离线微基准不代表游戏帧率收益。

原生校验覆盖在用的饰面、名称、HUD 和手套入口。已停用的实时刀型／动画构造地址不在认证范围，刀型仍走临时 Demo 重建。

升级：退出仍加载旧 DLL 的进程，只加载一个语言版本。保持原有智能应用分流；默认 T/CT 手套、模型变更、贴纸与挂件从原始录制重建临时 Demo。

详细记录：[稳定性审查](../diagnostics/stability-audit-20261117.md)、[工坊换图根因](../diagnostics/map-remap-manifest-20261116.md)。

## English

- Publish the immutable configuration and revision together, preventing mixed-version reads. Cache the derived live config and avoid repeated profile copies in maintenance polls, factory checks and knife refreshes.
- Stop control-panel busy loops when occluded, minimized or failing presentation. Preserve edits and background rewrite tasks across graphics-device failure; Insert recreates graphics resources. Validate backbuffer resize and render-target recreation after unbinding the previous target.
- Check VPK payload ranges before allocation and bound directory strings. Foreign-thread frame callbacks forward the original function exactly once without modifying game-thread-owned state.
- Include the Beta Workshop manifest signature repair. Runtime and offline tests share the resolver for all 11 map hook sites, retaining unique-match and atomic-install protections.
- Preserve cosmetic routing, HUD name synchronization, default T/CT glove reconstruction, five sticker slots, keychains, the fixed8 Demo repair, all 19 Doppler/Gamma Doppler variant labels and locked transparent radars.
- Refresh release artwork and the real native-panel capture; ship both languages, complete corresponding source and SHA256 checksums.

Validation: full C++ regressions, 42 parser tests, 30 ordinary rewriter tests, 12 real-panel scenarios, isolated bilingual DLL loading and offscreen rendering pass. Six external-recording rewriter tests remain ignored; the real-Demo matrix was not rerun. The embedded rewriter and all 19 radar reference resources retain their verified bytes.

Installed compatibility baseline: CS2 `2000943 / 1.41.9.7`, SourceRevision `11228971`; HLAE compatibility record: `2.193.0 / AfxHookSource2 0.42.0`. CS2/HLAE were not started for this release. In-game map, frame-time and long-session/seek acceptance remain pending; offline microbenchmarks are not an FPS claim.

Native checks cover active finish, name, HUD and glove entries. Retired live model/animation construction addresses remain outside certification; knife models use Temporary Demo reconstruction.

Restart the process carrying the old DLL and load one language only. Preserve the existing per-item Smart Apply routes; regenerate default T/CT gloves, model changes, stickers and keychains from the original recording.
