# nSkinzCS2 v0.7.0

2026-11-04 · Stable release / 正式版

## 中文

- 新增挂件位置预览。蓝色标记与 X/Y 滑轨实时联动，沿枪模定义的可挂区域移动。画布沿用贴纸预览的深色网格和枪型轮廓，支持预览新旧枪模。
- 临时 Demo 重建按录制中的枪模选择对应坐标。自定义位置适用于新增挂件和移动已有挂件。自动模式下，空槽从默认挂点开始，已有挂件保留原位置和 seed。
- 空槽新增时，重新初始化残留的 seed 和附属贴纸属性。兼容原有挂件配置。

选择 XUID、枪型和挂件，启用自定义位置后拖动蓝色标记或调整滑轨。完成后，从原始录制重新生成临时 Demo，即可在游戏中应用。面板预览即时更新。

[挂件预览面板实拍 / Native panel capture](../assets/keychain-panel-v0.7.0.png)

验证覆盖原生面板截图、C++ 和 Rust 回归，以及真实 AK-47 Demo 的 16,509 条自定义位置记录回读。自定义位置的游戏内显示仍需实测。默认挂点新增已由用户在游戏内确认。测试客户端为 CS2 2000940。

## English

- Preview keychain placement on the same weapon canvas and dark grid used for stickers. The blue marker follows mouse drag or the X/Y sliders and snaps to model-authored mount regions.
- Temporary Demo reconstruction selects coordinates for the recorded model variant. Custom placement supports both adding and moving a keychain. Automatic placement preserves existing mounts and seeds and uses the model default for an empty slot.
- Adding a keychain to an empty slot resets residual seed and attached-sticker attributes. Existing profiles remain compatible.

Choose a player XUID, weapon and keychain. Enable custom placement and adjust the blue marker. Generate a new Temporary Demo from the original recording to apply the position in CS2.

Validation covers the native panel capture, C++ and Rust regressions, and readback of 16,509 custom position records in a real AK-47 Demo. Custom placement still needs in-game visual acceptance. The user confirmed default-mount addition in-game. The verification client was CS2 2000940.
