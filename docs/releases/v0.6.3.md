# nSkinzCS2 v0.6.3 — Knife HUD identity synchronization

Release date / 发布日期：2026-10-31。**Stable release / 正式版**。

## 中文说明

本次 v0.6.3 以当前完整功能集重新定版，重点修复刀具实际模型／涂装已改变，但右侧武器栏仍显示旧刀名或旧皮肤名的问题。

- **模型＋饰面仍只走临时 Demo**：重建器以“玩家 XUID＋目标刀型＋目标涂装”生成独立经济物品身份；刀实体与 `player_death` 的 `weapon_itemid` 使用同一身份，右侧武器栏、实际外观和击杀信息不会继续复用旧库存名称缓存。
- **仅饰面仍只走当前 Demo 热修**：不写刀型定义、模型、动画图或 Subclass，只更新涂装材质及客户端物品身份。完整状态验证会检查身份、SOC 脱离、初始化、账户、品质、fallback 和名称字段；稳定后仍进入低开销快速路径。
- **默认 T／CT 手套与挂件仍只走临时 Demo**：没有接入实时创建或实时字段替换路径。枪械、五槽贴纸、自定义位置预览、工坊地图／雷达、手套目录、刀型目录和挂件目录继续保留当前实现。
- **目录完整性保留**：包括运动手套“隐知”（`1417`）、廓尔喀刀、94 个真实手套涂装、20 种市场刀型及纪念品挂件继承模型信息。
- **新增源码卫生门禁**：GitHub main、版本标签及 Pull Request 会检查受跟踪的文件名、文件内容和提交消息；命中被禁止的第三方标识时直接失败。门禁自身不保存可读的被禁止名称。

### 使用方法

1. 完全退出旧 DLL 所在的 CS2／HLAE 进程，只加载一个 v0.6.3 语言 DLL。
2. “模型＋饰面”、默认 T／CT 手套或挂件变更后，从原始录制重新生成临时 Demo；旧生成文件不会自动更新。
3. “仅饰面”在正在播放的原始／生成 Demo 中选择涂装并点击“更新”。
4. 保持同一刀型连续切换两个名称不同的涂装，确认实际材质、右侧名称和刀杀击杀信息一致。

### 验证与边界

- 完整 C++ 回归通过；Rust 重写器 23 项测试通过，4 项真实文件测试按环境保持忽略。
- 真实混合 Demo 重写验证 128 条死亡事件，刀实体与目标刀杀事件的完整物品身份一致；同一玩家／同一刀型更换涂装时高低位身份均变化。
- 中英文 DLL 全量重编译为 0 错误；源码、DLL、Windows ZIP 和源码 ZIP 均通过源码卫生检查与 SHA-256 核对。
- 原生兼容基线仍为 CS2 Client/Server `2000935`、Patch `1.41.9.2`、Steam Build `26144732`，HLAE `2.192.8`／AfxHookSource2 `0.41.8`。离线字段和构建测试不能代替 Panorama 与实际画面的最终验收。

## English notes

This v0.6.3 reissues the current complete feature set and fixes stale right-side knife/finish names after the rendered model or paint has already changed.

- Model + Finish remains Temporary-Demo-only. The reconstructed knife entity and matching death events share an identity derived from player, target knife definition and paint.
- Finish-only remains a live material hotpatch. It does not write the knife definition, model, animation graph or subclass; it refreshes only the paint/material state and the client identity consumed by the HUD.
- Default T/CT gloves and keychains remain Temporary-Demo-only. Existing firearm, five-slot sticker, custom placement preview, Workshop map/radar and complete cosmetic catalogs are retained.
- A permanent repository check rejects blocked third-party identifiers in tracked paths, contents and pushed commit messages on main, version tags and pull requests, without storing the readable blocked names in the check itself.

Restart CS2/HLAE, load one language DLL and regenerate reconstructed items from the original recording. Existing generated files are not repaired automatically. For Finish-only, select the paint and press Update in the playing source/generated Demo.

The full native suite, 23 regular rewriter tests, a 128-death real-Demo reconstruction, both language builds and package/source hygiene checks pass. In-game Panorama text and rendering remain final acceptance items. The native baseline remains CS2 `2000935` / Patch `1.41.9.2` / Steam Build `26144732`, HLAE `2.192.8` / AfxHookSource2 `0.41.8`.
