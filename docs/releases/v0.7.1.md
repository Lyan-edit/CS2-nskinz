# nSkinzCS2 v0.7.1

2026-11-05 · Stable release / 正式版

## 中文

- 修复智能应用中刀从“模型＋饰面”切换到“仅饰面”时被当作撤销模型覆盖的问题。切换后保留当前临时 Demo 的刀型，实时应用涂装、磨损、Seed、名称等配置，不为这次切换重新加载原始 Demo。
- 单独保存已成功重建的刀模型事务。后续因贴纸／挂件再次重建时保留这份模型数据，新的“仅饰面”涂装继续走实时路径。禁用刀配置仍会撤销该模型覆盖；加载原始录制会清理本次播放的模型记录。
- 新增智能应用按钮：枪械涂装、刀仅饰面以及已确认的原有非默认手套仅饰面实时应用；刀型、默认／生成 Demo 手套、手套模型、贴纸和挂件通过临时 Demo 重建；地图独立改动只重载当前播放文件。
- 临时 Demo 重建缺少已启用且填写 XUID 的饰品配置时，提前取消并弹窗说明原因。仅换地图无需填写 XUID。已填 XUID 但挂件记录未匹配时另行提示检查玩家和枪型。
- 更新本机 CS2 `2000942 / 1.41.9.6` 的材质、名称及右侧 HUD 原生入口；补齐枪械热修改后的名称刷新，并按完整武器句柄分别保存刀、主武器和手枪的标签请求。
- 保留挂件蓝色位置预览、五槽贴纸预览、完整饰品目录和固定 Inferno Water 透明雷达标准。

使用方法：载入临时 Demo，选择对应 XUID 的刀配置，切换为“仅饰面”并选好皮肤，点击“智能应用”。此模式只改变播放时的外观，不把新涂装写回磁盘上的 `.dem`。需要新刀型时选择“模型＋饰面”，从原始录制重新生成。

发布前完整 C++ 回归已通过，包含分流状态、当前安装文件的材质／名称／HUD 指令与直接调用、中文饰品目录及地图／雷达检查。原生面板截图、重写器 25 项普通回归、DLL 内嵌资源校验均通过；本机另有三份真实录制的默认 T／CT 手套重建验证。新增切换行为的游戏内最终显示仍需实测。此前测试沙箱的雷达缓存写权限限制已在本次发布验证中解除。详情见[兼容性记录](../diagnostics/cs2-2000942-20261105.md)和[智能应用说明](../development/smart-apply-20261104.md)。

## English

- Fix switching a reconstructed knife from Model + Finish to Finish-only: keep the current Demo's knife model and apply the new finish live, without reloading the original recording for this switch.
- Retain the last successful knife reconstruction transaction separately from the live finish. Later sticker/keychain rebuilds preserve that model while Finish-only paint remains live. Disabling the knife profile removes its model override; loading the original recording clears the playback model record.
- Add Smart Apply routing, missing-XUID preflight explanations, map-only reloads and localized keychain-target failures.
- Update material, item-name and right-HUD evidence for CS2 `2000942 / 1.41.9.6`, and synchronize firearm HUD names after verified live material application.
- Keep keychain placement previews, the five-slot sticker canvas, catalog coverage and the locked Inferno Water transparent radar standard.

Load the Temporary Demo, select the knife profile for its owner, choose Finish-only and a compatible paint, then press Smart Apply. Live changes do not modify the on-disk `.dem`. Model changes still require reconstruction from the original recording.

The complete C++ release regression passed, including routing transitions, installed material/name/HUD byte evidence and direct-call targets, the Chinese catalog and map/radar checks. Native UI capture, 25 ordinary rewriter tests and embedded-resource validation passed. The local client also has default T/CT glove reconstruction checks across three recordings. In-game visual acceptance of the new switch remains pending. The earlier sandbox limitation on writing the native radar compiler cache was resolved for this release validation.
