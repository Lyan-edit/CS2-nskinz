# nSkinzCS2 v0.7.3

2026-11-13 · Stable release / 正式版

## 中文

- 适配本机 CS2 `2000943 / 1.41.9.7`，SourceRevision `11228971`，Steam Build `26598758`；核对 HLAE `2.193.0 / AfxHookSource2 0.42.0` 接口。
- 重新定位枪械／刀具材质、原生物品名称、右侧 HUD 及手套刷新入口，保留严格指令、直接调用目标、完整实体句柄及拥有者校验。
- 同步 Pawn 手套字段后移 `0x30` 的布局，统一两个原生调用前置检查，避免一处仍使用旧偏移。默认 T／CT 手套、生成 Demo 手套与换手套模型继续走临时 Demo 重建，不进入实时实体创建／改模型。
- 保留 Beta 中的 Demo 文件头修复：重建后同时回填 FileInfo 和 SpawnGroups 索引，独立检查命令边界及长度，错误文件不会自动加载。
- 保留各区域独立智能应用、枪皮与单个贴纸槽分开提交、刀／手套仅饰面按当前型号筛选涂装，以及固定 Inferno Water 透明雷达。
- 更新正式版版本标识、首页封面和真实控制面板截图，提供中英文 DLL、完整包、完整对应源码和 SHA256。

验证：完整 C++ 回归、29 个原生窗口、9 个直接调用、17 项安装签名及本机目录审计通过。默认手套跨录制验证覆盖 3 份 Demo、21 名玩家、1704860 条记录和 116 次独立 seek，包含 T／CT；29 项普通 Rust 回归通过。34 个枪模文件与上一基准一致，贴纸和挂件挂点无须调整。隔离 DLL 加载及内嵌重写器、19 个雷达资源校验通过。

本轮未启动 CS2 或 HLAE，实际显示及加载仍需游戏内验收；真实夹具早于这次游戏更新录制。详细证据见[2000943 适配记录](../diagnostics/cs2-2000943-20261113.md)、[Demo 资源索引修复](../diagnostics/demo-header-spawn-groups-20261109.md)和[独立应用说明](../development/smart-apply-20261104.md)。

升级：退出仍加载旧 DLL 的进程，只加载一种语言；从原始录制重新生成临时 Demo，旧生成文件不会自动修复。保存／加载只管理编辑器配置，请使用各区域对应的应用按钮。

## English

- Adapt to installed CS2 `2000943 / 1.41.9.7`, SourceRevision `11228971`, Steam Build `26598758`, and check the installed HLAE `2.193.0 / AfxHookSource2 0.42.0` interfaces.
- Relocate firearm/knife material, item-name, right-HUD and glove native entries while retaining exact instruction, direct-call, full-handle and ownership validation.
- Update the Pawn glove fields moved by `0x30` and share the native Schema guard between both call sites. Default T/CT gloves, generated-Demo gloves and glove model changes remain reconstruction-only.
- Keep the Beta Demo header fix: relocate FileInfo and SpawnGroups, then independently validate container boundaries/indexes before automatic loading.
- Retain independent per-item Smart Apply, separate firearm/sticker-slot submission, current-model Finish-only filtering and the locked Inferno Water radar.

Validation passes: full native regressions; 29 instruction windows, nine direct calls and 17 installed signatures; catalog coverage; 29 ordinary Rust tests; isolated DLL loading and embedded resources. Default-glove tests cover three recordings, 21 players, 1,704,860 records and 116 independent seeks across both teams. All 34 gun model files match the previous baseline, preserving sticker/keychain mount data.

CS2/HLAE were not started for this release. In-game visual/loading acceptance remains pending; real fixtures predate this game update. Restart the process carrying the old DLL, load one language only and regenerate Temporary Demos from the original recording.
