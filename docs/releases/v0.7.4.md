# nSkinzCS2 v0.7.4

2026-11-14 · Stable release / 正式版

## 中文

- 修复部分录制生成临时 Demo 时在 `serializer.rs` 报空字段表越界的问题。正确识别动画字段的 `fixed8` 编码，补齐固定 8 位读取、跳过和写回，避免高位字节造成后续实体读流错位。
- 修复错误日志在中文编译路径处截断的问题：即时／延迟日志统一以 UTF-8 写入；panic 生成明确的失败响应，面板错误附完整任务日志和响应文件路径。
- 刀具多普勒／伽马多普勒选项新增 19 个变体标注：红宝石、蓝宝石、黑珍珠、绿宝石及 P1／P2／P3／P4。覆盖特殊刀型对应的独立涂装 ID，中英文均支持；仅饰面与模型＋饰面继续按当前刀型筛选。
- 保持 CS2 `2000943 / 1.41.9.7`、SourceRevision `11228971`、Steam Build `26598758` 和 HLAE `2.193.0 / AfxHookSource2 0.42.0` 兼容基线。默认 T／CT 手套继续通过临时 Demo 重建。
- 更新首页封面、原生控制面板图片、完整对应源码和 SHA256 校验文件。

验证：用用户提供的 `9.dem` 复现原版失败，修复后单独手套及枪械／刀具／手套组合重建成功，用户已确认修复包验证成功。跨 4 份独立录制，28 名默认手套玩家，2,330,667 条记录和 158 次独立跳转检查通过，覆盖 T／CT。解析库 42 项、重写器 30 项普通回归及完整 C++ 回归通过；19 项刀具标签核对本机游戏目录，中英文 DLL 隔离加载与内嵌资源校验通过。

本轮正式版验证未启动 CS2／HLAE；游戏内显示仍需使用新版 DLL 实测。真实录制早于当前客户端更新，不代表新录制格式的全面认证。

升级：退出已加载旧 DLL 的进程，只加载一个语言版本；需要重建的项目请从原始 Demo 重新生成。
详细记录：[fixed8 根因及验证](../diagnostics/demo-fixed8-20261114.md)、[刀具变体标签对照](../development/knife-doppler-labels-20261114.md)。

## English

- Fix Temporary Demo reconstruction panicking on an empty serializer after animation fields declared as `fixed8` were incorrectly read as varints. Decode, skip and encode the declared 8-bit values consistently.
- Preserve complete UTF-8 diagnostics after non-ASCII build paths. Convert worker panics into explicit failure responses and include the complete job log/response paths in the panel error.
- Label all 19 knife Doppler/Gamma Doppler variants as Ruby, Sapphire, Black Pearl, Emerald or P1/P2/P3/P4, including the alternate knife-specific paint IDs. Both languages and both knife modes retain model-compatible filtering.
- Retain the CS2 `2000943 / 1.41.9.7` and HLAE `2.193.0 / AfxHookSource2 0.42.0` baseline; default T/CT gloves remain on Temporary Demo reconstruction.
- Refresh the homepage artwork and provide both DLLs, the full package, complete corresponding source and SHA256 checksums.

Validation: reproduce the original failure with the supplied `9.dem`, then successfully rebuild gloves separately and together with firearms/knife models. The user confirmed the repair package works. Cross-recording validation covers four Demos, 28 default-glove players, 2,330,667 records and 158 independent seek checks across both teams. All 42 parser tests, 30 ordinary rewriter tests, full C++ regressions, catalog-backed variant checks, isolated DLL loading and embedded-resource checks pass. External fixture tests run separately from the ordinary suite.

CS2/HLAE were not started for this release validation. In-game acceptance remains pending for the release DLLs; fixtures predate the current client update. Restart before loading one language DLL, and regenerate Temporary Demos from the original recording.
