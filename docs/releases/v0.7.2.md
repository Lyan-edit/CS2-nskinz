# nSkinzCS2 v0.7.2

2026-11-07 · Stable release / 正式版

## 中文

- 智能应用改为各项独立按钮。每次只合并当前饰品项的配置，其它编辑内容继续暂存；已应用的其它配置继续保留。刀仅饰面不会因为暂存贴纸、挂件或地图而连带走临时 Demo 重建。
- 枪械涂装与贴纸拆开提交；支持只应用当前贴纸槽，也可明确选择应用此枪全部五个槽位。
- 刀和手套的仅饰面模式先读取目标 XUID 的当前实际模型，仅列出该模型兼容的涂装。模型未确认、数据过期或饰面不兼容时不应用，不回退到全部枪械／刀／手套涂装。提供重新检测按钮。
- 模型读取不发布编辑器中的外观配置。运行时使用独立的 `nSkinzCS2.applied.json`，保存／加载 `nSkinzCS2.json` 只操作编辑器内容。
- 枪械皮肤、刀仅饰面及原始 Demo 已确认的非默认手套仅饰面保持实时路径；刀模型、默认 T／CT 手套、生成 Demo 手套、手套模型、贴纸和挂件继续使用临时 Demo 重建。默认手套不进入实时实体创建或模型替换。
- 后续重建其它饰品时保留已应用的手套和刀模型数据；地图按钮独立准备雷达并重载，应用饰品不重复准备地图资源。
- 更新首页版本封面与真实控制面板截图，保留固定 Inferno Water 透明雷达标准。

升级：退出仍加载旧 DLL 的进程，只加载一个语言版本。旧编辑器配置保留为暂存内容，请在各区域分别点击需要的应用按钮。刀／手套仅饰面需先填写目标 XUID 并加载／播放 Demo，等待显示当前型号。临时 Demo 页另有明确标注的高级批量重建操作。

本次以本机安装的 CS2 `2000942 / 1.41.9.6` 为验证基线。完整 C++ 回归、独立应用专项、隔离 DLL 加载、内嵌资源和原生面板检查通过；本轮未启动 CS2 或 HLAE，游戏内最终画面仍需实测。详见[独立应用说明](../development/smart-apply-20261104.md)及[兼容性基线](../diagnostics/cs2-2000942-20261105.md)。

## English

- Make Smart Apply independent for each item. Applying a knife finish excludes staged stickers, keychains and map edits; other applied items remain intact.
- Separate firearm finishes from sticker edits. Apply the selected sticker slot, or explicitly apply all five slots on the current firearm.
- Detect the target player's current knife/glove model before offering Finish-only paints. Unknown/stale models and incompatible paints are rejected; there is no unfiltered fallback. Add a detection retry control.
- Keep read-only model queries separate from cosmetic publication. Runtime settings use `nSkinzCS2.applied.json`; Save/Load only edits `nSkinzCS2.json`.
- Retain live firearm/knife finishes and eligible original non-default glove finishes. Knife models, default T/CT gloves, generated-Demo gloves, glove model changes, stickers and keychains remain reconstruction-only.
- Preserve previously applied gloves and knife model transactions during later rebuilds. Map/radar preparation is independent of cosmetic buttons.
- Refresh the homepage cover and unmodified native panel capture, retaining the locked Inferno Water radar standard.

Upgrade by restarting the process carrying the old DLL and loading one language only. Existing editor settings stay staged until their individual Apply buttons are used. Enter the target XUID and load/play a Demo to detect the current Finish-only model. The Temporary Demo tab retains an explicitly labelled advanced bulk operation.

Verified against the installed CS2 `2000942 / 1.41.9.6` baseline. Full native regressions, scoped-apply tests, isolated DLL loading, embedded resources and native panel checks pass. CS2/HLAE were not started for this release; in-game visual acceptance remains pending.
