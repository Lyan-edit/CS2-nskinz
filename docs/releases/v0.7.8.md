# nSkinzCS2 v0.7.8

2026-11-25 · 正式版 / Stable release

## 中文

- 枪械涂装按点击应用时携带的枪械实例生效。填写目标玩家的 XUID 并选择枪型，即使角色正在用刀、手枪或投掷物，也可修改背着的所选枪械。
- 修复已换肤枪械丢出和落地时恢复原涂装的问题。丢出或转交时，原实例继续使用应用后的涂装。后来捡到的其它枪保留原涂装，可以单独再次应用。
- 结果栏等待游戏确认。玩家未携带所选型号时，会提示原因及 Demo tick。跳转、地图重载或实体销毁后，如需修改当前枪械，请再次点击应用。

完全退出加载过旧版或测试版的 CS2，再加载 `Lyan_nskinz-v0.7.8.dll`。此版本包含中英文，默认简体中文。仅用于 HLAE 的离线 Demo 回放。

用户已在同一 Demo 中实机确认 `test4` 的枪械应用与离手效果正常。正式版使用该实现。本机核验客户端为 CS2 `2000950 / 1.42.0.1`，SourceRevision `11268945`。

## English

- Apply a finish to the selected firearm the target player is carrying when Apply is clicked, even while it is holstered.
- Preserve the finish on that firearm when it is thrown, dropped, or picked up by another player. Other firearms acquired later retain their recorded finishes until explicitly applied.
- The status line reports the game's confirmation or rejection, including the Demo tick. Apply again after a seek, map reload, or entity replacement to target the current firearm.

Restart CS2 before loading `Lyan_nskinz-v0.7.8.dll`. It includes Chinese and English in one DLL, with Simplified Chinese as the default. Use only with offline HLAE Demo playback.

The reporter verified the firearm application and drop behavior in `test4` on the same Demo. This release uses that implementation. Inspected client: CS2 `2000950 / 1.42.0.1`, SourceRevision `11268945`.
