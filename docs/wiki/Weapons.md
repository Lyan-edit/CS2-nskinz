# 枪械皮肤

适用版本：v0.7.6。枪械饰面使用当前 Demo 热修。

## 应用一把枪的涂装

1. 打开“枪械”，新增或选中左侧配置。
2. “物品”选择实际枪型，填写当前持枪者 XUID，勾选启用。
3. 从该枪兼容的皮肤列表选择涂装，设置参数。
4. 点击“智能应用此枪涂装”。
5. 让 Demo 刷新画面，检查实际涂装和右侧 HUD。配置完成后保存。

该按钮不提交同一枪上尚未应用的贴纸。贴纸需要使用自己的槽位按钮。

## 参数说明

| 参数 | 作用与操作建议 |
| --- | --- |
| 物品 | 规则匹配的枪型，M4A4 与 M4A1-S 分别配置 |
| Seed | 图案种子，编辑器归一到 0–1000；有图案变化的涂装才会有明显差别 |
| 磨损 | 0.0000001–1.0；数值越小通常越新，具体外观由涂装和模型决定 |
| StatTrak | 当前热修中，非负数表示计数值；`0` 是零计数，`-1` 用于不启用计数 |
| 游戏内名称标签 | 自定义物品名字；不改变涂装 ID 或枪型 |
| 配置名称 | 左侧规则的管理名称 |

修改任何参数后重新点击本枪应用。磨损不是贴图分辨率；Seed 也不是多普勒阶段开关。

## “不修改”和“原皮／无涂装”

“不修改”不等于移除原有皮肤。要明确请求原皮，选择“原皮／无涂装”后应用。对于已带有复杂材质状态的录制，若回到原皮仍显示旧材质，请记录 Demo、枪型和日志进行反馈，不要把所有问题都归因于磨损数值。

## 为什么列表没有某个皮肤

面板读取本机已安装 CS2 的物品目录及语言资源，并按当前枪型筛选兼容涂装。保存的旧涂装不适用时会标记不可用，不会默默换成另一款。

如果整把枪的可用数量异常、中文名称缺失，先确认本机 CS2 已更新、目录加载成功，以及选择的是正确枪型。目录尚未确认时，不会用全枪通用列表代替兼容筛选。

## 捡枪、多玩家与清除

给另一名玩家配置同款枪时，建立独立 XUID 规则。目标玩家不在当前 Demo、还未拿到该枪或观察错人时，不会因为点了应用就给任意玩家换肤。

想停用本枪饰面时，取消该枪配置的启用并应用该枪。若只想回到原皮，可使用明确的原皮选项。需要排除所有本次外观规则时，重新启动并播放原 Demo。

贴纸另见[五槽贴纸](Stickers.md)；右侧名称另见[HUD 与名称](HUD-and-Names.md)。
