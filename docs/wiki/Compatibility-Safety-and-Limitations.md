# 版本迁移、兼容性与功能边界

适用版本：v0.7.6，文档更新于 2026-11-21。

## 从旧教程迁移

| 历史用法 | v0.7.6 用法 |
| --- | --- |
| 刀模型＋饰面生成临时 Demo | 刀页独立应用，使用热修 |
| 默认 T/CT 手套补字段／重建 | 手套页模型＋饰面，使用热修 |
| 贴纸只能替换已有槽／通过重建应用 | 五槽新增、替换、清除和位置统一热修 |
| 挂件尝试实时新增 | 挂件全部恢复为临时 Demo 重建 |
| 总 Update 一次提交所有编辑 | 各项目有独立应用按钮，互不连带提交暂存项 |
| 保存后下次自动激活整套配置 | 新进程应用会话为空，逐项应用 |
| 手动品质下拉框 | 已隐藏；由当前路径维护相关状态 |

旧发布说明是对应版本的历史记录。查当前操作优先阅读本手册和 v0.7.6 发布说明，不能把不同版本的流程拼接使用。

## 当前验证基线

发布记录使用的本机客户端为 CS2 `2000948 / 1.42.0.0`，SourceRevision `11259529`。这是已记录的离线验证基线，不是对未来客户端的兼容保证。

已完成的本地验证包括：独立应用与会话隔离、热修／HUD／当前持枪者回归、稳定性与日志、双语独立加载与离屏渲染、11 处地图签名匹配、19 个雷达参考版本，以及真实 Demo 的仅挂件重建验证。详情见[发布记录](https://github.com/Lyan-edit/CS2-nskinz/blob/v0.7.6/docs/releases/v0.7.6.md)。

该次发布未启动 CS2/HLAE 做新的游戏内验收。自动测试与离线重写不能证明所有录制的动作、透视、长时间播放和帧时都正常。

## 旧 Demo 与新模型

有些历史录制没有目标刀或手套的模型／动画资源。允许尝试新模型不等于资源一定存在；已知失败记录会继续参与保护。不要通过清空这些记录来证明“已经修复”。

出现新的客户端、HLAE 或资源格式变化时，应保留准确版本与日志，等待相应适配结果。

## 预览边界

贴纸和挂件预览是具体枪模的相对位置辅助。贴纸块不包含每款图案的真实透明轮廓；挂件预览不运行游戏物理。最终效果还受曲面、透视、材质、模型版本和游戏刷新影响。

面板数值与图形预览即时联动，但游戏更新依赖对应项目的应用按钮。挂件每次提交位置都需要重新重建。

## 地图边界

换图替换世界资源，不会重新录制人物路线，不能为差异地图自动生成正确的碰撞、光照和道具轨迹。雷达透明度也不能修复世界几何本身缺失。

固定透明图按匹配的地图／资源版本复用。名称相同但资源已经改变时，应重新核对。锁定的 `inferno_water` 标准不通过滑轨重新清理。

## 库存与使用范围

只用于通过 HLAE、带 `-insecure` 启动的离线 Demo。不要在联机服务器加载。修改的是回放外观，不产生、交易或变更 Steam 库存饰品。

必要许可与署名保留在主仓库的 [NOTICE](https://github.com/Lyan-edit/CS2-nskinz/blob/v0.7.6/NOTICE.md)、[第三方声明](https://github.com/Lyan-edit/CS2-nskinz/blob/v0.7.6/THIRD_PARTY_NOTICES.md)及相应许可证文件；使用与分发应保留适用条款。
