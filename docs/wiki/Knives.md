# 刀型、刀皮肤与多普勒

适用版本：v0.7.6。**刀的两种模式都使用热修，不需要临时 Demo 重建。**

## 仅饰面

用于保留玩家当前刀型，只改变涂装、种子、磨损、计数或名称。

1. 在“刀”页选中配置，填写玩家 XUID，勾选启用。
2. 选择“仅饰面”。让目标玩家持刀并刷新几帧，等待当前刀型号检测。
3. 确认检测结果，从该型号兼容列表选择涂装。
4. 设置参数，点击刀的智能应用按钮。

若当前型号未确认，使用“重新检测当前模型”。不要通过把其它刀型的涂装 ID 硬填进 JSON 来代替检测。对临时 Demo 再改刀饰面，也使用这一路径。

## 模型＋饰面

用于更换刀型，也可把 T/CT 默认匕首换成目标刀型。

1. 选择“模型＋饰面”，明确选择目标刀型。
2. 从目标刀型的兼容列表选择涂装，设置其它参数。
3. 点击该刀配置的应用按钮，刷新画面并检查模型、动作和右侧名称。

当前模式的刀型选择是明确的目标。在这一路径中，涂装选项 `-` 表示目标刀型的原皮；不能把它理解成保留原刀型。

“允许旧 Demo 尝试新模型”默认勾选。它允许尝试录制中未出现的模型，并不保证资源或动画一定可用。已记录的失败模型仍可能被保护策略拦截。遇到模型切换闪退，应停止重复触发同一组合并附上兼容日志。

## HUD 与验证

本版保留原生右侧型号／涂装名称同步。外观已变但右侧仍是旧刀名时，先确认当前 DLL、应用对象、模式和实际刀型号，再按[HUD 排查](HUD-and-Names.md)提供证据。名称标签与标准皮肤名属于不同显示内容。

不要用历史教程要求刀型重建临时 Demo；v0.7.6 的临时 Demo 页面只处理挂件。
