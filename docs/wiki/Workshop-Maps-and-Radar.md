# 创意工坊地图与透明雷达

适用版本：v0.7.6。地图按钮配置资源重映射并重载当前 Demo，**不需要饰品 XUID，也不走挂件重建**。

## 更换地图

1. 在 Steam 创意工坊订阅目标地图，等待 CS2 完整下载。
2. 进入原始 Demo，打开“地图更换”，点击重新扫描。
3. 从左侧选择可游玩的目标地图，核对地图名和工坊 ID。
4. 点击“使用选中地图”暂存目标；确认“启用 Demo 地图替换”和源地图名正确。
5. 根据需要启用雷达黑底处理，点击地图的智能应用按钮。
6. 等待同一 Demo 重载，检查目标世界、雷达和玩家位置。

只选择列表中的地图或点击“使用选中地图”不会代替最终应用。一个工坊项目可能包含多张地图；扫描会筛选可游玩的顶层地图，skybox／prefab 不应当成独立游戏地图选择。

源地图名指录制原本使用的地图。程序会尝试自动填入；不要把目标工坊地图名误填到源地图栏。

## 透明底相关控件

| 控件 | 作用 |
| --- | --- |
| 去除雷达错误黑底 | 准备透明雷达覆盖并维护相关显示设置 |
| 黑色容差 | 对通用处理中的背景颜色分类阈值，过高可能误伤深色道路 |
| 深色道路恢复 | 在通用背景处理中保留邻近的深色细节；不是从零绘制地图道路 |
| 背景透明度 | 0% 为完全透明，100% 为不透明背景；并同步对应的 HUD 背景设置 |
| 恢复默认 | 恢复处理参数；仍需重新应用地图 |

透明图片和游戏 HUD 的独立圆形背景不是同一层。即使图片有 Alpha，`mirv_pov` 中仍可能看到单独的黑色圆底，因此应检查背景透明度并通过地图按钮重新应用。

## 固定参考图与版本记忆

本版内嵌 19 个经过核对的雷达参考版本。识别到相应地图／资源版本时优先复用参考透明图；它不是只按“inferno”一类简称套同一张图片，也不是在线云端下载任意玩家的缓存。

`inferno_water` 已使用锁定的干净参考标准。固定参考生效时，黑色容差和道路恢复可能被禁用；调整这些数值也不会重新生成或替换锁定标准。这是固定参考的预期行为。

地图名称相同但工坊 ID、资源内容或雷达版本已改变时，需要重新核对，不能保证旧参考仍精确适用。不要手工覆盖固定 PNG 或把不明雷达缓存混入正式 DLL。

## 道路缺失、黑点与颜色

先区分三种情况：

| 现象 | 需要检查 |
| --- | --- |
| 雷达外面的整块黑圆 | HUD 背景透明度、是否重新应用、`mirv_pov` 显示层 |
| 图片内部黑点、镂空、道路被擦除 | 是否命中固定参考、目标地图与资源版本、通用容差参数 |
| 世界里的地面、墙体、天空缺失 | 目标地图资源、源录制与目标地图几何关系；不是雷达像素问题 |

贴图本身的合法深色建筑不一定是多余黑点。若固定参考仍与实际不同，请提供工坊链接／ID、内部地图名、DLL 版本、地图页参数、游戏与雷达截图。对已锁定的 `inferno_water` 不需要反复增加道路恢复值。

## 恢复原地图

取消地图替换的启用并点击地图应用，随后重载检查。要取得干净原始对照，也可以在重新启动后、不应用地图配置的情况下播放原 Demo。

换图不会重新录制玩家轨迹或替目标地图生成新的碰撞、导航、光照。目标几何体差异较大时，玩家路径和原录像内容不一定与新场景完全吻合。
