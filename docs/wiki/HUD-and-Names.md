# HUD 名称与名称标签

适用版本：v0.7.6。

## 三种名称

| 内容 | 在哪里设置 | 用途 |
| --- | --- | --- |
| 配置名称 | 各配置编辑器上方 | 左侧列表的规则管理名称 |
| 游戏内名称标签 | 涂装参数下方 | 自定义物品名字 |
| 标准型号／涂装名称 | 由选择的模型和皮肤决定 | 右侧武器栏等游戏标准物品显示 |

把“配置名称”改成“蝴蝶刀”不会更换刀型，也不会强制把右侧 HUD 文本改成该字样。需要改名时填写游戏内名称标签；需要换刀型或皮肤时选择对应配置并应用。

名称标签留空时，当前应用使用默认自定义名 `nSkinz CS2`。空文本不是明确的“删除名称标签”功能。

## 本版同步范围

枪械热修和刀的两种模式保留右侧完整型号／涂装名称更新。判断时应同时核对实际模型、实际涂装、当前持有人与所用规则。

游戏中的不同显示区不一定是同一个控件。左下自定义卡片、持枪者提示、右侧武器栏、击杀信息不能互相替代作为唯一验证证据。

手套没有独立的右侧武器槽；不承诺在右侧生成一个手套名称栏。多普勒宝石／阶段的方括号说明是编辑器标注，HUD 使用游戏本地化名称。

## 验证步骤

1. 确认只加载 v0.7.6 的一个语言版本，填写当前物品持有者 XUID。
2. 对正确的枪械或刀点击该项应用，记录所选模式、型号、涂装与名称标签。
3. 让 Demo 刷新几帧，再观察右侧对应槽位。
4. 截图同时保留物品实体、右侧文字与相关配置，排除观察了另一把枪、另一名玩家或旧截图。

如果 Demo 正在暂停，先短暂恢复播放。不要通过反复重建挂件来尝试刷新刀名。

## 击杀信息

历史版本曾对重建刀的死亡事件做过身份处理。当前刀型走热修，不能据此承诺已把录制中的所有历史击杀事件永久改写。本手册的 HUD 同步说明指当前运行时物品显示；需要反馈击杀图标时，应单独标明回放 tick、攻击者与原刀型。

## 品质是什么

品质是经济物品的分类元数据，与纹理清晰度、磨损、宝石阶段不同。例如历史字段中的 `0` 与 `3` 表示不同的品质分类，不等于普通贴图和高清贴图。

v0.7.6 没有手动品质下拉框。相关状态由应用路径维护，StatTrak 使用独立计数字段。不要以修改旧 JSON 的 `quality` 作为修复 HUD 或材质的方法。
