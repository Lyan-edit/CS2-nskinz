# 手套与默认 T/CT 手套

适用版本：v0.7.6。手套仅饰面、换型号和默认 T/CT 手套均走当前 Demo 热修。

## 已有型号，仅换涂装

1. 打开“手套”，选中配置，填写玩家 XUID，勾选启用。
2. 选择“仅饰面”，等待当前手套型号检测。
3. 只在该型号兼容的列表中选择涂装，设置 Seed、磨损和可用的名称字段。
4. 点击此手套配置的应用按钮，恢复播放几帧后观察双手。

仅饰面不会把运动手套变成驾驶手套。想切换手套类别时使用模型＋饰面。

## 默认 T/CT 手套或更换手套型号

1. 选择“模型＋饰面”。
2. 选定目标手套型号，例如运动手套、专业手套等。
3. 从这个型号的列表选涂装；配置玩家的 XUID，勾选启用。
4. 点击当前手套的应用按钮，检查双手与袖口。

默认 T/CT 手套没有目标商品手套型号对应的彩色涂装，不能通过仅饰面实现跨型号更换。当前版本为该情况提供模型＋饰面热修，**不需要到临时 Demo 页重建手套**。

“允许旧 Demo 尝试新模型”的含义与刀相同：允许尝试并保留保护，不保证所有历史录制的资源、动画和干员组合都可用。

## 涂装缺失与“隐知”

目录按本机游戏数据识别手套涂装及适用型号，不能只按涂装 ID 高低或英文名称前缀判断类别。“隐知”等现代条目应在对应的运动手套类别中查找。

找不到条目时按顺序检查：本机游戏数据是否最新、检测／选择的型号是否正确、目录是否加载完成、搜索是否包含正确的本地化名称。若仍缺失，附上期望型号、皮肤中英文名、涂装 ID（如已知）和目录诊断。

## 品质与 HUD

当前面板不提供手动品质选项。品质是经济物品元数据，不会提高材质清晰度，也不是磨损。应用路径维护所需的物品状态；旧 JSON 中存在 `quality` 不代表当前热修会按它提供手动品质控制。

手套通常没有右侧武器栏的独立名称槽。不能以右侧没有“手套名称”来判定换手套失败；应观察实际双手和诊断。枪／刀 HUD 同步见[HUD 与名称](HUD-and-Names.md)。
