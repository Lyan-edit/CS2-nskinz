# 五槽贴纸、自定义位置与预览

适用版本：v0.7.6。**共有 5 个槽位；新增、替换、清除及位置参数都使用热修。**

## 新增或替换一个槽

1. 在枪械页配置正确的枪型和当前持枪者 XUID，勾选启用。
2. 在贴纸列表选择 `#1`–`#5` 中的目标槽。
3. 选择图案，设置磨损、缩放、旋转及位置。
4. 点击“智能应用当前贴纸槽”。

原枪没有贴纸时也可为选定槽新增。要一次提交这把枪的五个槽，使用“应用此枪全部 5 个贴纸槽”。这个按钮会明确提交空槽的清除意图，使用前检查全部五槽。

## 同款贴纸如何分辨

每个槽都有独立编号，即使五张图案相同也可以通过编号选择。预览中当前选中槽为**黄色**，其它已配置槽为**白色**。从列表或画布选中后再调整，避免误改另一张。

只应用当前槽时，其余未提交槽和源 Demo 的对应贴纸保留。应用过的其它槽也会继续维护。

## 参数

| 参数 | 当前编辑范围／含义 |
| --- | --- |
| 贴纸磨损 | 0.0000001–1.0，控制刮损程度 |
| 缩放 | 0.1–5.0，1.0 是倍率基准，不等于所有图案具有同样实体面积 |
| 旋转 | 0–360 度 |
| 自定义位置 | 开启后可编辑位移并拖动画布中的选中贴纸 |
| 横向／纵向偏移 | 当前槽坐标映射中的偏移数值，不是画布像素 |
| 使用预设位置 | 把当前槽设置为该枪模的明确预设起始位置 |

微调滑轨范围为 `-0.10000` 至 `+0.10000`，旁边数值框支持更精确的输入；普通加减步长为 `0.0001`，快速步长为 `0.001`。数字框可表达超出滑轨的偏移，但数值可输入不代表枪模表面能承载该位置。

建议从 `0.0001` 量级的微调开始，每次观察实际效果后再继续。偏移过大会让贴纸离开可投影的枪体表面。

## 预设与第五槽

预览按具体枪型及检测到的新／旧枪模选择位置数据。AK 与 M4A4 不共用一张泛化步枪画布。枪口按预览约定朝左；某些投影会呈倾斜视角。

部分模型只有四个材质原生预设，第五个位置由模型贴纸表面数据补充起点。第五槽不等于“游戏只支持四槽”。点击使用预设位置后，也要点击当前槽应用。

当前应用的槽使用预览对应的预设／自定义位置；不会继续让旧临时 Demo 的位置清单覆盖本次编辑。

## 预览同步到什么程度

拖动和输入数值会立即更新**面板中的预览**。提交到游戏需要点击当前槽或全部五槽的应用按钮。保存文件不会替代应用。

画布上的块用于表达投影范围、选中状态和相对位置，**没有复刻每个贴纸图案的透明像素轮廓**。实际图案比例、透明留白、枪体曲面、透视和投影裁切都会影响游戏内效果。因此，白块不重合不能保证真实图案完全不重合，画布也不是游戏三维渲染器。

## 清除与重合排查

清除一个槽：选中该槽，选择空图案／“无”，再应用当前槽。不要只删除左侧整把枪的规则。

发生重合时：先确认游戏确已收到当前槽应用；逐槽选中核对编号，恢复预设，再分别缩小倍率、做小幅位移并应用。确认新／旧枪模检测一致，检查第五槽是否离开可贴区域。仍有偏差时，提供五槽参数、选中编号、面板与同一枪模视角的截图，详见[故障排除](Troubleshooting.md)。
